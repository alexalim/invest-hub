# Invest Hub

내 PC를 서버로 쓰는 1~3인용 투자 도구입니다. 두 부분으로 되어 있습니다.

- **트레이딩**: 국내·미국 주식, 코인, 지수·환율·원자재 시세와 차트, 종목필터, 매매신호, AI예측(유사 패턴), 유사차트, 백테스팅, 모의투자, 차트게임, 매매일지, 커뮤니티, 알림
- **스타트업 투자 DB**: 투자/M&A 라운드, 스타트업·투자자·펀드, 뉴스, 지원사업, 투자 통계, 컬렉션, IR, 기업 비교

## 실행

```bash
./run.sh                 # http://<이 PC IP>:8700
```

처음 실행하면 의존성 설치와 화면 빌드를 자동으로 합니다 (Python 3.12, `uv`, Node 20 이상 필요).
시세 목록은 바로 채워지고, 전 종목 일봉(약 3,500종목)은 첫 실행 후 10~20분에 걸쳐 쌓입니다.
매매신호·AI예측·종목필터의 기술적 조건·차트게임은 일봉이 쌓인 뒤에 동작합니다.

PC가 켜질 때 자동으로 띄우려면 `deploy/invest-hub.service` 첫 줄의 설치 명령을 따르세요.

## 처음 가입

1. 서버를 켜면 `data/setup_code.txt`에 설치 코드가 생기고 로그에도 찍힙니다.
2. 브라우저에서 접속해 이 코드로 가입하면 관리자 계정이 됩니다. 설치 코드 파일은 그 뒤 지워집니다.
3. 다른 사람은 **설정 → 사용자 초대**의 초대 코드로 가입합니다.

## 선택 키 (설정 화면에서 입력)

| 키 | 받는 곳 | 쓰는 곳 |
|---|---|---|
| DART 인증키 | opendart.fss.or.kr (무료, 즉시) | 스타트업 화면의 기업 개황·재무·공시 |
| 공공데이터포털 인증키 | data.go.kr — 금융위원회 기업기본정보·기업재무정보, 국민연금공단 가입 사업장 내역 | 비상장 기업 재무, 고용 인원 |

키가 없어도 나머지 기능은 모두 동작합니다.

## 데이터 출처

- 국내·미국 주식, 지수, 환율·원자재·금리: 네이버 증권 공개 주소 (실시간 웹소켓이 아니라 3~5초 주기 조회)
- 미국 분봉 일부: Yahoo Finance
- 코인: 업비트 공개 API
- 스타트업 투자: 벤처스퀘어·스타트업투데이·비석세스·스타트업엔 RSS와 구글 뉴스 검색 기사를 규칙으로 추출
- 지원사업: K-Startup 모집 공고 목록

모두 공식 API 계약이 아닌 공개 주소라서, 상대 사이트가 형식을 바꾸면 해당 수집이 멈출 수 있습니다. 설정 화면의 작업 상태에서 오류를 볼 수 있습니다.

## 알려진 한계

- **AI예측**은 학습된 모델이 아니라 "지금 차트와 닮은 과거 구간이 이후 어떻게 움직였나"의 통계입니다.
- **투자 라운드 추출**은 기사 제목 규칙 기반이라 회사명·금액·단계를 잘못 읽거나 해외 딜을 국내로 분류할 수 있습니다. 관리자는 투자/M&A 목록에서 행마다 해외 표시·삭제로 바로잡을 수 있습니다. 투자자 이름이 뽑히는 건은 일부(약 20%)입니다.
- 투자 통계는 공개된 유치액 기준이라 중기부 통계(투자기관 집행 실적)와 다릅니다.
- 공공데이터포털 연동(금융위·국민연금)은 실제 키로 확인하지 못했습니다.
- 특허·국가 R&D·공공조달·등기 임원·웹 트래픽은 구현하지 않았습니다.
- 실계좌 주문은 한국투자증권 국내 주식·ETF 현금 주문만 지원합니다 (해외 주식·코인 실거래 없음).

## 실계좌 주문 (관리자 전용)

**주식·코인 영역의 모의투자 → 실계좌 (관리자)**. 다른 사용자에게는 메뉴가 보이지 않고, 서버도 관리자 요청만 받습니다.

- 키: KIS Developers에서 발급한 앱키·앱시크릿과 계좌번호(앞 8자리 + 뒤 2자리). **모의투자용과 실전용 키는 따로** 넣습니다. 값은 `data/kis.json`(권한 600)에만 저장되고 화면에 다시 나오지 않습니다.
- 기본은 **모의** 환경입니다. 실전 전환은 비밀번호로 잠금을 푼 상태에서만 됩니다.
- 주문 흐름: 비밀번호로 잠금 해제(10분) → 미리보기(한도 검사) → 45초 안에 확정. 확인 코드는 1회용이라 두 번 눌러도 주문은 한 번만 나갑니다.
- 안전장치: 1회 금액·하루 금액·하루 횟수 한도, 주문 실행 스위치.
- 증권사 응답을 못 받은 주문은 '결과 미확인'으로 남고 **자동 재전송하지 않습니다**. '증권사 내역과 맞추기'로 확인하세요.

## 5분봉 자료 (장중 단타 검증)

- 매일 15:50 이후 거래대금 상위 300종목의 5분봉을 네이버에서 덧붙입니다 (처음 60거래일은 야후).
- 한국투자증권 실전 키가 저장돼 있으면 `python -m app.kis_download 40`으로 최근 1년치(정규장 1분봉→5분봉)를 받을 수 있습니다. 이 키의 호출 한도가 초당 2건 안팎이라 종목당 약 17분이 걸리고, 중단 후 이어받기가 됩니다. 한투 자료에는 15:30 종가 봉(공식 종가)이 들어 있습니다.
- 앱의 국내 일봉은 넥스트레이드 포함 통합시세라 종가가 KRX 정규장 종가와 다를 수 있습니다.

## 관리

```bash
# 사용자·모의투자·게시글 등 사용자 데이터만 모두 지우기 (시세·일봉·투자 DB는 유지)
cd backend && .venv/bin/python -m app.maintenance --reset-users
```

데이터는 `data/hub.db`(SQLite) 한 파일입니다. 백업은 서버를 멈춘 뒤 이 파일을 복사하면 됩니다.

## 구조

```
backend/app/
  providers/   시세 수집 (네이버, 업비트, 야후) + 통합 계층
  analysis/    지표, 조건식, 백테스트, 매매신호, 유사차트/AI예측, 종목필터
  vc/          기사 수집, 라운드 추출, 지원사업, 기업 보강(DART 등)
  routers/     API
  trading.py   모의투자 엔진     game.py  차트게임     jobs.py  주기 작업
frontend/src/  Vue 3 + lightweight-charts
```
